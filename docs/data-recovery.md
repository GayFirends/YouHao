# 数据恢复与升级

油迹的本地数据库是应用私有的 Room 数据库 `fueltrack.db`。数据库在启动时启用外键并执行 `PRAGMA quick_check`；关键写入与合并在事务内完成，升级失败不会覆盖原数据库。

建议在升级和启用云端加密前导出 JSON 备份。JSON 是完整恢复格式，CSV 仅用于查看和分析。

恢复顺序：先保留当前数据库和云端文件的副本，再尝试在“设置 → 备份与导出 → 导入备份”中导入最近的 JSON 备份；不要使用空数据库覆盖尚未确认的云端文件。导入是合并而不是替换，采用与同步引擎相同的 last-writer-wins 规则，较新的记录优先，删除标记同样保留。若应用仍能进入设置页，可以导出脱敏诊断信息供排查，诊断包不含车辆记录、WebDAV 地址、用户名、密码或同步口令。

本地数据库由更高版本的应用创建时，旧版本会拒绝打开，必须升级应用，不应清空数据或降级 schema。

当前数据库 schema 为 v1（重写后的第一个原生版本）。冲突表 `sync_conflicts` 只保存待处理的本机与云端版本；解决冲突后对应行会在同一事务内删除。

WebDAV 主快照同步成功、但设备水位文件更新失败时，业务数据仍视为已同步，墓碑清理则会跳过。此时不要删除云端 `.meta.json` 文件；修复权限或服务器条件写入支持后再次同步即可恢复安全清理。

## 从旧版 WebView 客户端迁移

旧版 Vue + Capacitor 版本使用名为 `fuel-track` 的 SQLite 数据库，原生版**刻意不复用**该文件名，因此两者互不影响：

1. 在旧版中导出 JSON 备份；
2. 安装原生版；
3. 在“设置 → 备份与导出 → 导入备份”中选择该文件。

目前没有把旧数据库二进制直接转换为 Room 数据库的一次性工具；JSON 备份导入是受支持且已测试的迁移路径。
