# 数据恢复与升级

油迹会在 Web 数据库升级前创建内部安全快照，升级失败时不会覆盖原数据库。Android 数据库迁移在 SQLite 事务内执行。

建议在升级和启用云端加密前导出 JSON 备份。JSON 是完整恢复格式，CSV 仅用于查看和分析。

恢复顺序：先保留当前数据库和云端文件的副本，再尝试导入最近 JSON 备份；不要使用空数据库覆盖尚未确认的云端文件。若应用仍能进入“数据与同步”，可以导出脱敏诊断信息供排查，诊断包不含车辆记录、WebDAV 地址、用户名、密码或同步口令。

数据库由更高版本创建时，旧客户端会拒绝打开，必须升级应用，不应清空数据或降级 schema。

当前数据库 schema 为 v5。v5 新增的同步冲突表只保存待处理的本机和云端版本；解决冲突后对应行会在同一事务内删除。升级前 Web 会保留内部 SQLite 快照，恢复快照时仍会执行完整性检查和必要迁移。

WebDAV 主快照同步成功、但设备水位文件更新失败时，业务数据仍视为已同步，墓碑清理则会跳过。此时不要删除云端 `.meta.json` 文件；修复权限或服务器条件写入支持后再次同步即可恢复安全清理。
