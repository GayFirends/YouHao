# 发布与兼容政策

- 支持最新稳定版本和前一个次版本。
- 本地数据库、JSON v1 备份和 WebDAV v1 文件保持向前迁移兼容，不允许静默清库。
- 正式支持当前 Chromium 系浏览器与 Android API 23–35；Firefox、Safari 和 iOS 不作为发布阻断平台。
- 发布必须通过类型检查、Lint、格式、覆盖率、桌面/移动 Chromium E2E、依赖高危审计、构建体积预算和 Android Release 构建。
- 每次发布在变更日志中记录数据库 schema、同步格式、最低兼容客户端和不可逆迁移。

## 当前版本矩阵

| 应用版本 | 数据库 schema | 同步格式                      | 最低兼容客户端                     | 回滚限制                                                             |
| -------- | ------------: | ----------------------------- | ---------------------------------- | -------------------------------------------------------------------- |
| 0.2.x    |             5 | v1 明文读取/写入；v2 加密可选 | v1 明文可由旧版读取；v2 需要 0.2.x | schema v5 数据库不可由未知旧版安全降级；启用 v2 前须升级所有同步设备 |

发布候选必须完成旧数据库逐级升级、JSON 恢复、WebDAV 条件写入冲突和 Android 进程重启演练。Android CI 在 API 23 与 API 35 运行 instrumentation；候选 APK/AAB 还需校验版本号、签名和 R8 后安装启动。
