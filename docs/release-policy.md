# 发布与兼容政策

- 支持最新稳定版本和前一个次版本。
- 本地数据库、JSON v1 备份和 WebDAV v1 文件保持向前迁移兼容，不允许静默清库。
- 客户端的正式支持范围是 Android API 26–37。iOS 尚未实现，不作为发布阻断平台。
- 发布必须通过领域层与应用层单元测试、Android Lint 与 R8 后的 Release 构建。
- 每次发布在变更日志中记录数据库 schema、同步格式、最低兼容客户端和不可逆迁移。

## 当前版本矩阵

| 应用版本 | 数据库 schema        | 同步格式                      | 最低兼容客户端                     | 回滚限制                                                             |
| -------- | -------------------: | ----------------------------- | ---------------------------------- | -------------------------------------------------------------------- |
| 0.2.x    | 1（Room，`fueltrack.db`） | v1 明文读取/写入；v2 加密可选 | v1 明文可由旧版读取；v2 需要 0.2.x | 原生版与旧 WebView 版是独立数据库，无二进制迁移路径；启用 v2 前须升级所有同步设备 |

发布候选必须完成 JSON 恢复、WebDAV 条件写入冲突、加密容器互操作和 Android 进程重启演练。Instrumentation 与启动冒烟测试在 Android API 26 与 API 35 的模拟器上运行；候选 APK/AAB 还需校验版本号、签名和 R8 后安装启动。
