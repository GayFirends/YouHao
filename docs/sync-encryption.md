# WebDAV 同步加密

同步加密默认关闭。启用后，油迹使用 PBKDF2-HMAC-SHA-256 派生密钥，并使用 AES-256-GCM 加密 gzip 压缩后的完整 v1 同步快照。每次上传都会生成新的 salt 和 IV。

同步口令与 WebDAV 密码不同，默认只保留在当前会话中，不会进入本地数据库、JSON 备份或云端文件。Android 用户可明确选择“在此设备记住口令”；应用使用 Android Keystore 的 AES-GCM 密钥加密口令，并只把密文放在应用私有存储中。Web 不长期保存口令。项目不提供口令恢复；遗失口令后只能使用此前保存的明文 JSON 备份。

启用前应升级所有设备。旧客户端会拒绝读取 v2 密文，因此不会继续覆盖云端文件。停用或修改口令前，先成功解密并下载当前文件，再用新设置重新上传。

每个 WebDAV 地址和文件名分别保存同步基线及设备确认信息，切换服务器不会沿用另一同步目标的冲突判断。同步目录中会出现一个 `<同步文件名>.meta.json` 设备水位文件；它不包含业务记录或凭据。软删除至少保留 90 天，并且只有所有已知设备都确认同步到删除之后才清理。长期停用的设备会让清理继续延后，但不会影响正常同步或手动备份。

同一条车辆或加油记录在本机和云端都发生变化时，应用会保留两份版本，不再静默覆盖。请在“数据与同步”中选择保留本机、保留云端，或手动编辑合并后的 JSON；解决结果会以新的更新时间参与下一次同步。
